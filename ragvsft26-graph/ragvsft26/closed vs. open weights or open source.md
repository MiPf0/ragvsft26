- Open weights vs. open source - what does that mean?
	- open source: complete code, training data and methodology are available under permissive license; completely reproducible
	- open weights: only the trained model parameters are released, often with significant restrictions on use; not the same as truly open source AI

- Hugging Face, "the GitHub of Machine Learning": platform, community & set of tools/libraries
	- central hub for open-source AI community
	- provides infrastructure and tools
		- models: pre-trained like Llama 3, 100.000+ models available for free
		- datasets: hosts huge library of datasets, standardized and ready to use
		- spaces: hosting live demos of AI models
